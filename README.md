# 🏢 BauTools — Architecture & Zoning Suite for Autodesk Revit

**Author:** Arch Sergio Castro  
**Target:** Revit 2026 / Revit 2025 (.NET 8.0)  

---

## 🌟 Included Tools

### 1. 📐 Zoning & Area Panel
* **`ZFA Calculator`**: Multi-building zoning floor area calculation suite with Typical Floor multipliers, non-destructive area propagation, multi-building matrix, and automatic sheet diagram generation.
* **`NYC Lot Boundary`**: Direct NYC Digital Tax Map & GeoClient parcel boundary generator with BBL validation.
* **`Neural Generative Zoning`**: Real-time 3D interactive massing generator with 360° orbital navigation, dormer/setback controls, and 1-click baking into Revit Design Options.

### 2. 🏛️ Levels & Views Panel
* **`Create Levels`**: High-speed batch level & floor plan view generator with custom floor heights.
* **`Rename Levels`**: Batch renaming with prefixes, suffixes, regex search & replace, and sequential numbering.
* **`Bubble Heads`**: Instant synchronization and toggling of Grid & Level bubble heads across views.

## 🚀 2 Easy Installation Options

### Option A: pyRevit Extension (1-Click)
1. Double-click `install_pyrevit.bat`  
   *OR* clone this repository into `%APPDATA%\pyRevit\Extensions\BauTools.extension`.
2. Open Revit, and **BauTools** will appear as a dedicated tab in pyRevit.

### Option B: Native Revit Add-in (1-Click)
1. Double-click `install_native.bat`.
2. Open Revit 2026, and **BauTools** will appear as a native top-level Ribbon tab.
